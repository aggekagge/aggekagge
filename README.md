## Projects

Some of the projects I've worked on include:

- **GIROvis:** Interactive visualization and analysis of global investment risk using economic and terrorism data, with Machine Learning and Data Mining Techniques/Algorithms for Analysis. [Not yet finished]
- **[Machine Learning Web Application Pose Recorder](https://github.com/aggekagge/machine-learning-web-app-pose-recorder):** A full-stack application for recording, analyzing, and evaluating human body movements using machine learning. The system uses **MoveNet** to extract 2D body keypoints from video recordings and trained ML models to transform these into **3D Kinect-style coordinates** for interactive skeleton visualization. Additional models predict **movement quality (AIMO score)** and classify the **weakest link** in a movement. Built using **Python, FastAPI, MLflow, Node.js, JavaScript, and Docker**. The models were trained primarily on squatting exercises, but the system can be adapted to other movements through additional training.
- **[Hotel2 - Hotel Management & Booking System](https://github.com/aggekagge/hotel2-booking-system):** An object-oriented desktop application for managing hotel operations, developed using **Java, JavaFX, and MySQL**. The system allows receptionists to manage guest records, create and manage room reservations, check room availability, and handle guest check-ins and check-outs. It features an **interactive calendar-based dashboard** displaying bookings, arrivals, and departures, along with an administration panel for managing rooms and staff accounts. Built using **JavaFX for the graphical interface, JDBC for database communication, Gradle for project management, and Docker for database deployment**.
